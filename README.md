# 📉 Weight Tracker App

A simple and customizable weight tracker built with **React Native** for Android.  
Track your body weight, visualize your progress, and stay consistent with smart **reminders** and intuitive **charts**.

---

## ✨ Features

- 📆 Daily weight logging with history  
- 📊 Interactive weight graph with trends  
- 🔔 Customizable reminders (daily, weekly, monthly)  
- ⚙️ Simple settings for personal goals and units  
- 💾 Local storage with future option to sync  

---

## 🔧 Tech Stack

- React Native  
- TypeScript  
- React Navigation  
- Reanimated / Victory Native (for charts)  
- Expo Notifications (or Capacitor for push notifications)
